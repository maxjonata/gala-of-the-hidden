# Gala of the Hidden — GitHub Pages

Public static presentation for Gala of the Hidden. Source copied from the maintained project site in `website/dist/`.

## Publish

The GitHub Actions workflow in `.github/workflows/pages.yml` deploys this repository root to GitHub Pages whenever `main` changes. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The page is in Portuguese with an English language toggle. Project plans and implemented work are identified separately.
